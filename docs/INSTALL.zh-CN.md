# 安装与升级 ReadyCheck

[English](INSTALL.md) · [版本通道](../README.zh-CN.md#选择版本)

## 选择安装包

- macOS 需要 Apple 芯片（arm64）及 macOS 14+。
- 最新可下载公开预览为 **0.7.0-dev.23**，稳定发布通道为 **0.6.1**。
- **0.7.0-dev.28** 是最新已验证源码/打包候选，源码 tag 已公开，但尚无公开 GitHub Release 安装包资产。有效下载入口见 [README 版本表](../README.zh-CN.md#选择版本)。
- Windows 为独立 x64 便携客户端，见[Windows 指南](WINDOWS.zh-CN.md)。

## 在 Mac 安装

1. 下载所选已发布版本的 Mac DMG。
2. 打开映像，将 ReadyCheck.app 复制到“应用程序”。
3. 从“应用程序”打开 ReadyCheck。

Mac 预览包沿用 ReadyCheck 稳定自签名身份，尚非 Developer ID 签名/公证包。若 macOS 阻止首次打开，正常批准入口在**系统设置 → 隐私与安全性 → 仍要打开**；更新后也可能需要正常钥匙串确认。

## 连接服务

| 服务 | 设置 → 连接中的操作 | 读取范围 |
| --- | --- | --- |
| Codex | 选择 Codex，点击登录 ReadyCheck，完成浏览器 OAuth。 | 实际返回的配额窗口与匹配账号的能力。 |
| DeepSeek | 选择 DeepSeek，直接在原生应用内输入 API Key。 | 官方 API 余额、币种及赠送/充值分项，不是网页/手机聊天用量。 |

Codex 正常回调使用 `localhost:1455`；自动完成失败时，可使用应用中的最终回调 URL 兜底入口。完整回调 URL 属于凭据，不要公开分享。

已有钥匙串访问受阻时，使用**重试读取凭据**并完成系统提示，无需重新替换 Key。每家服务的断开控件只移除其自身保存的凭据；账号/连接历史保持隔离。不要通过 Issue 或聊天发送密码或 Key。

## 升级

1. 替换应用包前先正常退出 ReadyCheck。
2. 将新版复制到同一“应用程序”位置并重新打开。
3. 需要时完成正常钥匙串提示，再确认每条连接能取得新读数。

当前升级路径保留既有设置、Widget 保存位置、历史及按账号的用卡授权。Dev.28 已通过同包退出重开及 13 项显示/选择/位置偏好的精确比较；这不代替系统登录/重启或全部迁移/设备验收，见[当前检查](versions/0.7.0/QA.zh-CN.md)。

## 找到常用控件

- **总览：**读数、本机历史与账户权益；当前源码默认展开权益。
- **设置 → 提醒：**独立配置额度、恢复、到期和 DeepSeek 余额规则；自动用卡需另行按账号授权。
- **设置 → 显示：**胶囊/贴边、信息卡片、刘海、置顶及显示控件；普通点击胶囊仅预览，固定按钮才保持展开。
- **设置 → 通用：**语言、刷新间隔、登录启动及检查更新。
- **通知记录：**投递/撤回结果；卡片结果仍在“用卡与检查记录”中。

源码运行见 [README](../README.zh-CN.md#构建与参与)，分发核验遵循[发布流程](RELEASE.zh-CN.md)。
