# 0.1.137：原稿表盘气泡与贴边竖条

[English](PLAN.md) · [黑盒验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

用户否定 0.1.136 平面化预览，本版按选定原稿调整。

| 需求 | 成功标准 |
| --- | --- |
| 原稿外观 | 柔和收腰的连续外壳，金属圆形表盘边框、刻度、粗同心额度弧和独立 C 标记；详情含额度色点、分隔线、倒计时和蓝色打开入口。 |
| 贴边竖条 | 自由圆球拖到任一侧缩成细竖条，两条长度随真实剩余额度变化；向内展开，拖离边缘恢复自由圆球。 |
| 原有交互 | 保留半秒悬停、点击固定、Esc/外部收起、保存位置、全部窗口详情滚动及卡片/贴边圆环/刘海入口。 |
| 数据正确 | 使用现有额度和观测小图，不伪造实时数据，不增加轮询。未知/过期保持未知。每个五分钟小图桶以四根细线呈现同一个观测值，不代表四次独立观测。 |

范围：macOS 圆形气泡样式修订，Windows 仅同步版本。本轮本地构建、安装、验证和提交；没有要求公开推送或发布 Release。
