# ReadyCheck 0.7.2 验收

## 0.7.2 正式版

- 本版沿用已验收的快捷展示、服务顺序、菜单栏图标和每分钟读取。连接凭据、本机历史、提醒和自动用卡授权使用原有数据格式。相关保留项见[功能保留矩阵](../0.7.0/RELEASE_AUDIT.zh-CN.md)。
- 扩大信息卡片标题拖动区域。刘海测试分别验证有可显示服务时展开详情、无服务时打开显示设置。用量节奏测试使用已登录且与快照匹配的账号，紧凑读数测试按真实快捷展示筛选验证空态和失败。
- 20 项 Swift 专项测试通过，覆盖此前 4 项失败。Mac 分发沿用 ReadyCheck 自签名身份。Windows 403 原设备未列入本版修复，原设备复测仍待完成。

- 公开源码的 macOS 全量验证共 555 项，失败 0 项，3 项可选原生取证跳过。挂载 DMG 后校验了磁盘映像、严格签名、版本、内置 Muse 读取脚本和私人路径。正式版已安装并从「应用程序」打开，胶囊保存位置与前版一致。
- 安装版的连接、快捷展示与总览都按 Codex、Muse、DeepSeek 排列。三项勾选均保留，通用页显示固定每分钟刷新。Muse 沿用已有会话并成功读取额度。
- 用户确认两项钥匙串授权后，安装版 0.7.2 显示 Codex 5 小时和 7 天的真实配额，以及 DeepSeek 的真实余额、赠送和充值分项。两项手动刷新均显示成功，Muse 继续显示周额度。
- 本地 Windows ZIP 通过 CRC、版本和全部 16 项打包网页源码比对。发布 ZIP 由 GitHub 工作流在 Windows 上通过 Electron 界面和代理网络检查后上传。

## 0.7.2-dev.11 每分钟自动刷新

- **A07、A08。** 按用户要求将 1／3／5 分钟选择器替换为固定 1 分钟和设置说明。旧间隔偏好不再生效。手动、唤醒和额度事件刷新延续原有入口。回退到前一版本可恢复选择器。账号凭据和历史格式保持原有结构。
- Codex 的周期刷新独立于窗口可见状态。macOS 的 Codex、DeepSeek 和 Muse 使用同一刷新策略，今后接入的服务常规轮询也使用该策略。DeepSeek 图表的 5 分钟代表历史聚合粒度。
- Windows 预览仍支持 Codex，固定每分钟刷新，已有的旧刷新间隔偏好不会改变计时。
- 开发验收运行 36 项 Swift 专项测试，其中 1 项按配置跳过，其余通过。Windows 在 Node 24 下通过检查、冒烟及 UI 冒烟测试。真实账户刷新周期、菜单栏点击与原报 OAuth 403 的 Windows 设备待实测。
- 已从公开 DMG 安装并打开。通用设置只保留固定每分钟刷新的说明，Muse 详情页也显示该间隔及真实读数。钥匙串确认后，Codex 显示已登录，DeepSeek 显示真实余额。完整的后台刷新计时待实测。
