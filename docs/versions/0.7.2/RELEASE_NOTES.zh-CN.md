# ReadyCheck 0.7.2 正式版

[English](RELEASE_NOTES.md) · [验收](QA.zh-CN.md)

- 设置、总览、用量、服务目录、菜单和聚合胶囊统一为 **Codex → Muse → DeepSeek**。键盘导航和筛选后的服务也沿用这个顺序。
- ReadyCheck 运行时每分钟自动刷新已连接服务。设置里以说明替代间隔选择，手动刷新继续可用。刷新只读取用量或余额。
- macOS 可在**设置 → 显示 → 快捷展示**勾选胶囊和菜单中展示的服务。右侧窄胶囊按显示项数调整高度，空选时可从胶囊进入设置。
- macOS 顶部菜单栏只显示一个 ReadyCheck 图标，点开可看已勾选服务。鼠标在胶囊服务间移动时，侧窗内容淡入切换。
- Windows 继续支持 Codex，自动刷新也固定为 1 分钟。

- 扩大信息卡片标题的拖动区域。无可显示服务时，点击刘海可直接进入显示设置。

Mac DMG 沿用 ReadyCheck 自签名身份。Windows x64 便携版支持 Codex，原报 OAuth 403 的电脑仍待复测。 [验收记录](QA.zh-CN.md)
