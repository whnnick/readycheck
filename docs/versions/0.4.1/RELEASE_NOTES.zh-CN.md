# ReadyCheck 0.4.1 — 提醒及时，减少重复打扰

[English](RELEASE_NOTES.md) · [验收](QA.zh-CN.md) · [范围](PLAN.zh-CN.md)

- **每个到期节点只提醒一次。** macOS接受同卡同节点的提醒后，刷新、关闭通知或重启不再重复提交。72／48／24／12小时的后续节点仍独立保留。
- **凭据重试保留去重。** 账号暂时未知不再清空原账号到期标记，不同账号的投递记录继续隔离。
- **通知历史更准确。** 区分已提交与通知中心已验证，明确提交失败仍可重试；横幅是否显示由macOS控制。
- **项目首页更清晰。** 中英文重排产品价值、原生界面证据与下载入口，应用“关于”突出本次修复。

额度、下一步、账户权益、Token统计、Widget最近一小时图、菜单栏／刘海及提醒开关均保留。自动用卡延续原有按账号授权和成功通知，本版不新增兑换动作。

本次修复仅针对macOS，Windows保留原界面并同步版号。Mac为Apple芯片自签名预览，非Developer ID签名、未公证。自动化生命周期／账号场景及当前Mac刷新验收不冒充第二真实账号、外接显示器、Windows硬件或真实用卡验收，详见[验收](QA.zh-CN.md)。
