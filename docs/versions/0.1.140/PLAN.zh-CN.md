# 0.1.140：清楚的详情固定按钮

[English](PLAN.md) · [黑盒验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

| 需求 | 成功标准 |
| --- | --- |
| 用途 | 悬停提示说明移开鼠标后保持详情展开，明确不是窗口置顶。中文/英文、保持展开/预览两态分别说明，允许应用在后台时显示提示。 |
| 反馈 | 按钮一直显示，保持展开时为蓝色实心钉且辅助功能可读出状态；容器通用提示不覆盖按钮提示。 |
| 切换 | 预览→保持展开；保持展开→悬停预览。移开只收起预览，取消待执行计时，取消固定时释放键盘焦点；收起/拖动中不能切换。保留外部/Esc收起及现有布局。 |

范围：macOS固定按钮可用性与此前浮窗修订，Windows同步版本。按标准发布流程交付源码和两平台新构建的0.1.140产物；此前0.1.139包不是0.1.140产物。
