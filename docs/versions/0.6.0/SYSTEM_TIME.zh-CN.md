# 系统通知时间：再次出现，仍未解决

[English](SYSTEM_TIME.md) · [验收](QA.zh-CN.md) · [上一轮调查](../0.5.5/SYSTEM_TIME.zh-CN.md)

2026-10-28：用户再次提供真实到期提醒和额度恢复提醒截图，副标题完整发送时间存在，右上角系统时间仍缺失；旁边手机镜像的天气通知有时间。这不能证明时间只属于手机镜像：之前本机原生A/B通知同样显示过。临时测试出现时间，不等于正式提醒已验收。

正式代码仍使用标准UNNotificationRequest、立即触发和系统代理呈现选项；没有自设系统投递日期，也没有自绘通知卡片。Apple将UNNotification.date定义为系统在通知中心显示的只读投递日期。目前缺失标签的根因仍未确认，副标题只是兜底，不是系统右上角显示的修复。

本次签名隔离只读程序查询通知设置和现有已投递记录，不初始化产品模型、不访问账号凭据、不发送新通知、不改规则或删除原通知。宿主当前为macOS27.2，通知设置可读取，但返回已投递列表为空。此结果**不能证明**正式通知缺日期、日期正确，或截图通知已被清除；辅助程序也可能未观察到正式应用的通知上下文。用户随后确认截图通知已经清除，因此空列表有了解释，不是日期无效的证据。

辅助程序已退出，临时注册已移除并恢复安装应用注册；17项偏好与授权/尝试摘要一致。未修改生产代码、安装包、通知样式或权限。纯文档观察不需要新增应用测试；私有截图与诊断输出不作为公开素材。

来源：[Apple通知投递日期](https://developer.apple.com/documentation/usernotifications/unnotification/date)。

## 确认后的正式应用测试

从安装应用设置中提交一条明确标记的测试通知，通知由产品发出，不由辅助程序伪造；产品确认在通知中心查到。随后只读查询返回这一条记录：系统投递日期有效、不在未来，触发方式为立即投递。这证明正式代码路径中的本机通知可以具有有效系统日期，不能据此验证已经清除的夜间提醒，也不能宣称修复缺失标签。已再次移除辅助程序注册并恢复安装应用注册。用户确认这条正式测试通知右上角仍没有时间，因此“系统保存了有效日期”不等于“系统正确绘制了时间”。原生工具仍选中电池组件；提醒规则、授权与真实卡片未改。

## 呈现方式对照未形成修复证据

隔离程序原计划比较标准前台呈现、已弃用的alert兼容选项和后台投递。实际上只发出了后台请求：自动进入前台失败，界面工具也无法选中同标识辅助窗口。两个前台变体均未完成测试，不能比较选项，更不能下因果结论。第一次后台记录的日期有效；正式呈现方式未改。

辅助程序已停止。精确清理本次3条测试通知：正式测试和两条仅后台的对照请求；复查这3条剩余为零，未动其他通知。临时注册移除、安装应用注册恢复，仅原产品进程继续运行。17项偏好、授权与尝试摘要一致。右上角时间仍未解决，原生样式和完整日期兜底保留。

参考：[Apple前台通知呈现选项](https://developer.apple.com/documentation/usernotifications/unnotificationpresentationoptions)。

## 显示进程刷新与应用身份核查

从安装应用设置中另发一条测试，应用报告通知中心记录已验证。随后仅重启系统 NotificationCenter 显示进程，通知服务与 ReadyCheck 进程继续运行。用户重新打开通知中心后确认，这条测试右上角仍无时间，因此重启显示进程**未解决本次问题**。未清空通知数据库、权限或通知记录。该测试暂留供核对；由于没有取得精确标识，本次未删除它。

只读检查发现，正式 bundle identifier 仅有一条 LaunchServices 注册，指向安装应用，执行文件、名称和图标均符合预期。安装包 Info.plist 为 `LSUIElement=false`，没有 `LSBackgroundOnly` 标记；程序入口明确选择普通应用激活策略。严格深度代码签名校验通过。这些检查没有发现可修复的身份或仅后台配置错误，但不能证明系统所有渲染路径都正常。

本机 SDK 将投递日期定义为只读，公开通知内容属性中没有强制显示系统时间标签的选项。截图中的天气通知还带有“即时通知”顶部信息行，这是视觉差异，不能据此确认原因。把 ReadyCheck 改为“即时通知”会改变包括专注模式处理在内的打扰行为，不应作为时间标签修复。立即投递及标准 banner/list/sound 呈现选项保持原样。

刷新前后，17 项偏好、已保存的自动用卡授权和尝试记录摘要均一致，未使用真实卡片。没有修改生产代码、安装包或版本，也未公开发布。本次纯文档更新检查链接、空白与敏感内容；既有应用测试结果不代表新增视觉验收。系统右上角时间仍未解决，目前未找到有证据支持的应用代码补丁。
