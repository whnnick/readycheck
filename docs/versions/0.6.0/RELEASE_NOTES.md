# ReadyCheck 0.6.0 — Clearer reminders and card records

[中文](RELEASE_NOTES.zh-CN.md) · [Checks](QA.md)

- Filter notification history by type and browse local date groups, with recorded relative and complete times.
- Follow the available evidence for each reset card in a read-only timeline. Missing historical results remain unconfirmed.
- Find an appropriate recovery action for connection or data problems without changing reminder rules or card authorization.
- New macOS notifications include a full submission date and time. The system's upper-right relative time is not reliably shown; see [investigation](SYSTEM_TIME.md).

Existing settings, account history and automatic-card authorization are retained. No real card was redeemed during testing. macOS is a self-signed preview, not notarized; Windows retains its existing interface. See the checks for device and test limits.
