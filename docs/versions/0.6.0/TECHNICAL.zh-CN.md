# 0.6.0 原生展示契约

[English](TECHNICAL.md) · [计划](PLAN.zh-CN.md) · [验收](QA.zh-CN.md)

不新增账本、持久化格式、提醒规则或授权。通知页读取现有本机记录，类型筛选仅为视图状态，默认全部。本地日历分组使用实际最近尝试时间，仅在缺失时回退到已记录接收时间；未知时间单列，不能使用卡片到期日代替。可见行每分钟更新相对时间，同时保留完整时间；系统原生通知沿用0.5.5完整发送时间副标题。

用卡时间线读取现有账号隔离后的执行投影。保留的请求准备时间、最近记录状态、最近通知尝试与验证分别展示。这些是保存的证据节点，不是完整网络日志；卡片观察不能当作兑换请求，历史到期提醒不补造时间线。关联成功通知需本机已确认用卡结果、精确请求ID、类型与到期日全部匹配；其他记录仍保留在原通知历史中。账户级检查因原元数据没有卡片ID而单独保留。

连接操作优先保留正在进行的登录，其次处理凭据受限。明确认证拒绝才打开原登录设置，普通读数故障提供刷新。解析器支持问题提供检查更新；不安全或未校准端点转设置，不直接重试。执行前重新核对操作仍适用，避免旧按钮覆盖新状态。打开登录设置本身不启动OAuth、不删凭据、不改授权、不兑换卡片；既有刷新/后台行为仍遵从用户原授权，验收不测试真实兑换。

生产页面已有滚动容器。较矮的通知/更新重点测试画布现在同样使用ScrollView，保留原视口尺寸断言；未删除内容或放宽高度阈值掩盖溢出。设备实点与全量回归分别在QA记录。
