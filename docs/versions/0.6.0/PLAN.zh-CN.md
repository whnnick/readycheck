# 0.6.0 — 提醒与用卡，一眼看明白

[English](PLAN.md) · [黑盒验收](QA.zh-CN.md) · [版本](../../VERSIONS.md)

用户已确认开发方向。本阶段本地开发，未授权公开发布。保留尚未发布的0.5.5完整发送时间改动；系统原生提醒样式不变，不能保证系统右上角相对时间始终显示。

## 交互与边界

1. 通知记录页：在现有页面顶部提供类型选择，默认全部；按本地日期倒序分组，未知日期单列，显示相对时间和完整时间。日期只取记录的实际通知尝试时间，缺失时可用已记录系统接收时间，不能使用卡片到期日代替。筛选没有结果与完全没有记录分别表达；筛选、分组和刷新不补发通知。
2. 用卡详情：直接展示现有观测、检查、请求与结果和通知的证据；不增加新Tab或嵌套折叠。只有可关联到这张卡的记录进入时间线；账户级检查不能冒充卡片级记录，当前聚合状态不能伪造过去事件。保留原事实、未确认原因、通知详情和关闭/Esc。
3. 异常：沿用已有连接恢复与检查接口，按凭据受限、认证失效、网络/服务故障给出准确动作；不把估算不足或卡片详情暂缺当作登录失效。仅在有准确状态证据时映射操作，不增加自动重登或兑换。

先完成通知筛选与日期分组及数据测试，再做原生预览与窄窗双语验收，随后完成卡片详情与异常操作。可见变更使用0.6.0-dev.1，未验收内容明确标待验。

## 功能保留

逐项沿用[65项基线](../0.3.0/FEATURE_RETENTION.zh-CN.md)及[0.5.4验收](../0.5.4/QA.zh-CN.md)。账户权益、订阅日期、Credits、卡片次数与到期日、Token页、本地额度图、最近1小时图、Widget拖动/固定/贴边/圆形、点击刘海、菜单栏、关于、双语、快捷键和全部提醒规则保持。OAuth单入口不恢复旧本机主登录。偏好、账号隔离、历史、去重、自动用卡授权与规则不迁移不清空。

只读显示改进不兑换真实卡；测试通知与用卡成功分开。成功标准是用户无需跨多处猜测，即可辨认事件时间、结果证据与可用操作，不把系统接收等同用户看见通知。
