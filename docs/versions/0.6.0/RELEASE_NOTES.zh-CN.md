# ReadyCheck 0.6.0 — 提醒与用卡记录更清楚

[English](RELEASE_NOTES.md) · [验收](QA.zh-CN.md)

- 通知记录支持按类型筛选、按本地日期分组，并查看相对时间和完整记录时间。
- 重置卡详情以只读时间线呈现已有证据；缺少历史结果时保持未确认。
- 连接或数据异常时，根据实际情况提供对应处理入口，不改变提醒规则和用卡授权。
- 新的 macOS 通知正文保留完整发送日期和时间；系统右上角的相对时间仍可能不显示，详见[排查记录](SYSTEM_TIME.zh-CN.md)。

原有设置、账号历史和自动用卡授权保留；测试未消耗真实重置卡。macOS 是未经公证的自签名预览，Windows 保留原有界面。设备和测试边界详见验收记录。
