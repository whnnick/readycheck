# 0.6.1 — 功能保留核对

[English](RELEASE_AUDIT.md) · [0.6.0 逐项 65 项基线](../0.6.0/RELEASE_AUDIT.zh-CN.md) · [验收](QA.zh-CN.md)

沿用 0.6.0 逐项审计、对应证据和设备边界。本次只修改系统通知默认点击的响应：打开现有通知记录页并刷新记录；关闭通知不跳转。通知投递、门槛、去重、账号和用卡授权的实现未改。安装开发包后，运行中及冷启动的真实测试通知点击均已验收，提醒设置、通知历史、OAuth 和自动用卡授权可见。测试未消耗真实重置卡；不宣称 65 项均在本版重新实机验收，Windows 保留原有界面。
