# 0.1.143：紧凑表盘间距

[English](PLAN.md) · [验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

问题：圆球中的百分比压到内圈，C标志占比过大。

| 需求 | 成功标准 |
| --- | --- |
| 百分比留白 | 80%、100%、0%和未知状态在92点圆球内均清楚可读，不压内圈。 |
| 标志比例 | C标志更小，标志与数字之间有间距；整体仍位于内圈中央。 |
| 范围 | 保持圆环几何、圆球及展开尺寸、展开后的标志大小和拖动/悬停/固定交互。 |

范围：macOS紧凑圆球中心内容及上一版0.1.142直接拖动修复。交付本机更新和0.1.143公开发布：净化源码、注释标签、macOS DMG及Windows便携ZIP，并核对远端资产与latest。Windows同步版本信息，宣传素材不属于本次发布。
