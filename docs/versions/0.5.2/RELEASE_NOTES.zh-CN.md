# ReadyCheck 0.5.2 — 登录更简单，账号更清楚

[English](RELEASE_NOTES.md) · [验收](QA.zh-CN.md) · [功能保留审计](RELEASE_AUDIT.zh-CN.md)

- **只需登录 ReadyCheck。** 统一使用 OAuth 登录及读取主额度，移除本机账号选择、认证回退和订阅文件缓存补丁。
- **原账号的设置与授权保留。** 历史和原自动用卡授权不会清除；同账号确认后继续，不同账号不会继承授权。
- **连接恢复，无需重启。** 新鲜额度恢复连接，缓存及迟到旧结果不能误恢复。启动先核对登录再检查用卡，成功检查后撤回旧凭据警告，诊断历史保留。
- **常用能力继续保留。** 双额度、订阅与卡片权益、Token统计、提醒、记录、Widget一小时图、菜单、刘海和关于保留。后台Codex接口继续提供同账号统计和用卡能力。

脱敏公开源码一次运行415项全通过，Windows检查、烟雾／界面行为检查及双平台包内容核验通过。最终DMG安装后，经macOS钥匙串确认，同账号OAuth、权益和Token数据已恢复；17项偏好和原用卡授权未变。没有为测试兑换真实卡。macOS更新，Windows保留原界面。稳定自签名预览，未做Developer ID签名或公证；新构建可能需macOS再次确认钥匙串访问。
