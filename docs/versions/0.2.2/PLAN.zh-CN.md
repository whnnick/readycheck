# 0.2.2：可靠的连接状态与刷新

[English](PLAN.md) · [版本索引](../../VERSIONS.md) · [检查与覆盖边界](QA.zh-CN.md)

2026-10-19。仅本地开发，公开下载仍为 0.2.1。保留已认可的 Widget／卡片／刘海设计、设置、凭据及账号历史；本阶段未授权公开推送或发布。

1. 检查升级签名和凭据访问，不改真实钥匙串条目或访问控制。区分“签名要求一致”和“已有条目已授权”：安装版 0.2.1 与保留开发包使用相同身份／签名要求，但仅凭此不能解释或消除系统确认。
2. 用可控合成客户端复现迟到的连接读取与交叠刷新。切换账号来源后，旧本机／凭据读取结果及错误不能覆盖当前账号状态；新连接应立即刷新，旧请求结束不能清除新请求的刷新状态。
3. 验证网络失败缓存、恢复、唤醒触发刷新及现有低额度／恢复提醒去重。缓存或错误账号数据不能触发新额度提醒；保留 5%、10%、20% 及既有账户权益。

先补定向回归，再做最小修复，随后运行全量 Swift 并验收签名本地预览。私有签名／账号证据不进入公开源码。模拟网络／唤醒检查与真实断网、睡眠、显示器验收分别记录。macOS 正常钥匙串确认仍可能需要，不放宽权限、不强制重新 OAuth 登录来掩盖问题。不新增 Codex 任务自动停止／恢复能力。
