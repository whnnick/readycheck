## 覆盖与发布边界

真实睡眠唤醒、持续断网、多显示器／Spaces、其他用户钥匙串和真实账号切换仍待设备验收。合成测试不代表这些场景的实机结果。Windows 仅同步版本元数据，连接模型修改仅适用于 macOS。不新增任务自动停止／恢复。应用仍为自签名预览，未经 Developer ID 签名或公证。

真实账号数据／截图、私有路径及签名细节保留在源码之外，保留稳定包供回退。后续发布需单独通过既有公共同步、产物及远端验收流程。
