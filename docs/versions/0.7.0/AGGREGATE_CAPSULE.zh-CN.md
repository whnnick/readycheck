# 聚合胶囊 — dev.32 设计约定

[English](AGGREGATE_CAPSULE.md) · [验收](QA.zh-CN.md)

参考用户提供的五张 Token Monitor 图片，以及该项目的[官方 Edge Dock 展示](https://github.com/Javis603/token-monitor#showcase)，核对日期 2026-11-08。借鉴信息层级与聚合交互，不复制其源码、素材、跨设备能力或账号数据。

1. 单个 84 × 392 点竖向胶囊同时显示 Codex、DeepSeek、Muse，Codex 优先；统一 48 点图标/圆环区、数字字号、间距和石墨玻璃外壳。本机 dev.32 已选用聚合展示，双环和卡片可在显示设置中切换。
2. Codex 保留 5h/7d 两圈剩余额度，并明确标注两项数值；Muse 为周额度单圈。DeepSeek 只有中性轮廓、币种与余额，不虚构剩余百分比。未知、过期、错误与未连接状态明确显示；不相加不可比数据，不编造 Token、会话或 tok/s。
3. 悬停或普通点击预览对应服务详情，详情在胶囊侧边展开，聚合胶囊持续可见。悬停不改变主窗口服务；仅标注的固定按钮保持展开。取消固定、移出、Esc、点击外部沿用原交互规则。主窗口与设置入口定位到当前查看服务。
4. 顶部/底部把手拖动，限制于屏幕内并可贴左右边；聚合位置独立保存，首次沿用原胶囊中心，保留旧模式位置、显示/全屏/稍后显示偏好。详情向空间充足的一侧展开并限制于屏幕内；预览不抢焦点。
5. 完成门槛：三种数据、中英文均可读，无溢出，不将真实账号截图加入仓库；验证服务选择、左右展开、显式固定、收起、位置恢复、全屏行为及旧双环。专项回归与签名验证后仅本机安装，不公开 push/tag/Release。
