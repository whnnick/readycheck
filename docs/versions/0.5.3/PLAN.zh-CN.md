# 0.5.3 — 通知记录独立入口

[English](PLAN.md) · [验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

已发布：`0.5.3`；开发验收为`0.5.3-dev.2`。用户批准通知记录独立成页、移除总览底部重复提醒入口；用户现已明确授权打包推送。

- 左侧按总览、Token用量、通知记录、设置排列。保留原页面Command1／2／3，新增Command4打开通知记录；原生全屏快捷键保留。
- 通知页直接展示完整本机历史、各类投递状态和空状态，沿用主窗口滚动区。刷新只重新载入本机记录，不刷新额度或补发通知。通知投递与卡片兑换结果分开。
- 设置→提醒保留全部开关、阈值、到期节点、自动用卡授权／规则和通知测试；移出内嵌历史摘要及“查看全部”弹窗入口。卡片详情里精确关联的通知弹窗保留。
- 总览仅移除底部重复提醒快捷卡片及单一阈值摘要。菜单栏和Widget的提醒快捷入口仍打开设置。

不改持久化格式、凭据、账号归属、授权、历史、提醒调度／去重、用卡条件或网络接口。通知页和卡片关联弹窗共用原记录行；不新增筛选器或配置。macOS展示调整，Windows仅同步元数据。

成功标准：侧栏及原生菜单直接进入，原快捷键保留，完整记录不限三条，刷新不改变规则，中英文最小窗口深浅色可读，相关回归及签名本地安装通过。沿用[0.5.2审计](../0.5.2/RELEASE_AUDIT.zh-CN.md)的其他能力及实机边界；D09历史入口和总览快捷卡片的导航变化不删除提醒能力。
