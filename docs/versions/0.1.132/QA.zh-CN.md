## 部分完成与真实环境待验收

- 本轮未发生真实低额度阈值跨越。具体提醒已由判定器和通知客户端测试覆盖；低额度横幅在正常使用中观察，不额外消耗额度制造触发。
- 完整等待 30/60 分钟后的自动恢复、休眠过期后唤醒、多屏及减少动态效果，仍需真实环境验收。截止时间逻辑测试不等于真实休眠/唤醒验收。
- 展开、收起静态界面检查不能证明逐帧动效；本版本不宣称新增动画实现。
- 主窗口中英文预览、一小时隐藏和单一恢复按钮已验收。原生菜单栏布局仍需实机观察；共享控件编译通过，不等于本轮已完成菜单栏视觉验收。
- 更换最终签名二进制后，钥匙串再次要求确认；自动操作工具不能操作系统安全窗口，最终凭据确认由用户完成。此前安装的 0.1.132 构建已成功读取真实 OAuth 配额。私人截图证据位于忽略的 `.build/qa/0.1.132/english-snooze.png`。
- macOS 14、Windows 未实机验收；Windows 仅同步版本号。未进行真实退出登录后的自启动验收。
- 使用稳定自签名预览身份，未使用 Developer ID 或公证。凭据及含私人信息的界面证据不进入源码或发布材料。
