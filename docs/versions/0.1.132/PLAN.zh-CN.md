# 0.1.132：更安静的桌面额度监控

[English](PLAN.md) · [黑盒验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

2026-10-07 本地预览版。保留现有额度恢复提醒、圆形气泡、卡片和贴边圆环。

| 需求 | 实现行为 |
| --- | --- |
| 可选的提前提醒 | 默认关闭，在主窗口或菜单栏选择 20% 或 10%。当前、已验证的 Codex 配额跨过阈值时，每个账号、窗口、重置周期提醒一次。首次有效读取只建立基线，切换阈值重新建立基线。 |
| 暂时隐藏浮窗 | 显示设置、菜单栏和浮窗右键菜单提供 30 分钟、1 小时。应用运行期间继续监控，截止时间随重开应用保留；立即恢复会取消计时。启动与唤醒时检查过期截止时间。 |
| 清晰的样式选择 | 用三种示意预览区分自由拖动的圆形气泡、卡片与左右贴边的圆环。一次只显示一种，复用各样式已有的位置存储。 |
| 解释数据状态 | 主窗口及菜单栏入口显示本次读取来源、本次运行最近成功读取时间、最近尝试时间和相关原因。缺少许可、订阅日期时不推断；过去的订阅日期说明为历史记录。凭据失败时提供现有重试入口。 |

复用通知中心核验、通知记录、数据来源、窗口控制器和本地化，不新增模型生成请求、提供商、额度预测、账单抓取、动画模式或 Windows 功能。

低额度去重采用兼容旧记录的可选字段。投递失败用同一标识重试；投递等待期间关闭提醒或修改阈值，不会被旧结果覆盖。过期、估算、模拟、乱序数据不触发。缺少重置时间时，额度恢复到阈值以上再重新监听下一次下降。

验证包括阈值边界、投递与通知记录、隐藏截止时间持久化及数据说明，再验收安装后的真实界面。贴边悬停保持 0.5 秒，点击仍立即展开。详见[验收结果与发布待办](QA.zh-CN.md)。
