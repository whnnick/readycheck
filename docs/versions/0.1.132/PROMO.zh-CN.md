## 目标与产品证据

目标用户是使用 Codex 编程的 Mac 用户，渠道是小红书竖屏视频。前三秒钩子“额度见底，才发现？”，单一收益“少盯额度，少被打断”。证据来自当前 0.1.132 原生 SwiftUI 组件的匿名演示：13%/70% 配额、可选20%/10%低额度提醒、浮窗隐藏30分钟/1小时且刷新与已开启的提醒继续、三种样式预览。不会宣称增加额度或保证系统通知可见。

行动入口是 GitHub 搜索 whnnick/readycheck，在 [0.1.132 Release](https://github.com/whnnick/readycheck/releases/tag/v0.1.132) 下载。发布文案说明 Mac 要求 macOS14以上及预览签名首次安装说明；Windows另有便携包，视频演示的是Mac功能。

交付包括30秒1080×1920/30fps视频、独立1080×1440封面、中文发布文案、原创电子背景音乐。没有合成配音；交互合成标注为演示动画，配额标注演示数据；不展示真实账号、凭据或工作区内容。用于截图的临时原生测试已经验证并移除。
