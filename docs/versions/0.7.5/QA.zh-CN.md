# ReadyCheck 0.7.5 验收

[English](QA.md) · [更新日志](../../../CHANGELOG.zh-CN.md)

## 0.7.5 正式版

- [发布范围](RELEASE_NOTES.zh-CN.md)涵盖聚合胶囊和主窗口焦点。安装版的侧栏与设置菜单通过鼠标和方向键切换检查。原生窗口回归确认接收控件处理鼠标按下之前，焦点标记已隐藏。
- 公开源码共运行 562 项 Swift 用例，零失败，3 项需显式启用的用例跳过。14 项 Muse 读取测试通过。
- 使用 Muse 真实读数实测，点图标旁的空白可打开详情，从服务行拖动可移动胶囊且不会选中服务。反向拖动恢复原来的贴边位置和垂直中心。原生事件测试覆盖左右贴边首次直接内拖、轻微位移和底部独立菜单热区。
- 挂载 DMG 后通过版本、签名、资源、磁盘映像和二进制隐私检查。移走构建目录后，ReadyCheck 0.7.5 正常启动。
- Windows 便携包通过 Node 24 服务、应用接线、界面冒烟、ZIP 完整性和内部 16 个应用源码文件比对。Windows 应用逻辑沿用 0.7.4。原报 OAuth 403 的 Windows 电脑暂无真实账号复测条件。

## 0.7.5-dev.2 主窗口焦点

- 主窗口在将鼠标事件交给侧栏或设置控件之前先识别鼠标输入，避免按下到选中之间出现键盘焦点标记。键盘导航仍显示焦点提示。
- 21 项 Swift 专项测试通过。原生窗口测试确认接收控件处理鼠标按下之前，键盘焦点标记已隐藏。
- 移走构建目录后运行签名安装版。按住再松开「用量」，侧栏显示中性色玻璃高光。按上方向键回到「总览」时显示焦点环，Tab 移动焦点不切换页面。设置菜单的鼠标和方向键切换也已验证。

## 0.7.5-dev.1 聚合胶囊手势

- 服务行整行可点击、可拖动。移动不足 4 点时仍按最初按下的服务处理。拖动服务行或把手可以移动胶囊并收起详情。底部省略号独立响应点击。
- 34 项 Swift 专项测试通过。回归用例将原生鼠标事件送入窗口，覆盖轻微位移仍可选中、轻点把手、从两侧直接向内拖，以及拖完松手不会选中服务。
- 移走构建目录后已安装并打开签名版，桌面胶囊能显示真实读数。桌面端的完整拖动操作尚待实测。
