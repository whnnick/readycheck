# ReadyCheck 0.7.5

[简体中文](RELEASE_NOTES.zh-CN.md) · [Verification](QA.md)

- Click a service row anywhere in the macOS aggregate capsule to preview it. Drag from the row or either grip to move the capsule. Small pointer movements still count as a click.

- The Windows portable app continues to monitor Codex.

The macOS DMG uses the existing ReadyCheck self-signed identity and has no Apple notarization.
