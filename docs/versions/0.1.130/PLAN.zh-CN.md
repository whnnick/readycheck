# 0.1.130 气泡详情与主显示配额

[English](PLAN.md) | [验收](QA.zh-CN.md) | [版本索引](../../VERSIONS.md)

圆形气泡展开详情原来只保留两个配额窗口。本版取消截断，在原有 282 × 156 面板内竖向滚动，已选配额置顶，其他窗口仍保留。相同时长但 ID 不同的额度桶不合并；名称支持两行及完整悬停提示。保留蓝色打开链接和紧急程度颜色。

设置中的“主显示配额”明确只影响圆形气泡与刘海主显示。选择入口使用当前返回的窗口名称；偏好窗口缺失时菜单保留不可用项，显示临时回退提示，恢复后自动重新显示原偏好。旧版五小时／七天偏好适用同一规则。无数据不补造配额，不覆写用户偏好。

范围仅限上述 macOS 详情与选择行为，不新增样式，不改动贴边悬停时长、拖动或形状过渡。验收覆盖额外同周期窗口、零／一／多个窗口刷新、偏好缺失与恢复及原生截图；真实账号交互单独记录。Windows 仅同步版本号。
