## 目标与方案

目标用户：日常使用 Codex 编程的 Mac 用户。渠道：小红书竖屏视频笔记。
前三秒钩子：“写到一半，Codex 没额度了？”单一卖点：把剩余额度放在手边，帮助提前安排编程节奏。行动入口：GitHub 搜索 ReadyCheck，作者 whnnick；[最新安装包](https://github.com/whnnick/readycheck/releases/latest)。

成片 29 秒，1080×1920、30 fps；封面独立 1080×1440。六段依次呈现痛点、双配额、贴边常驻、展开与气泡、恢复提醒、下载入口。大标题和字幕避开上下平台控件及右侧操作区。上传页与封面检查已通过；笔记仍在审核中，公开移动端播放器安全区尚待验收。
