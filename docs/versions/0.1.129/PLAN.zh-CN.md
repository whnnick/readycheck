# 0.1.129 动态贴边圆环

[English](PLAN.md) | [验收](QA.zh-CN.md) | [版本索引](../../VERSIONS.md)

贴边胶囊原来固定展示五小时和周配额。本版按账号返回的每个有效配额窗口显示圆环，标签采用真实时长，额外额度桶有名称时同时展示。只有周配额的账号显示一个圆环，不补造五小时额度。缺失数据保持不可用，不能解释为无限额度。

范围：macOS 贴边圆环、收起后的进度条、对应详情和刷新后的原生浮窗尺寸。沿用点击整个胶囊显示详情、半秒悬停展开、左右贴边拖动、紧急程度颜色与其他浮窗样式。列表超过屏幕可见高度时支持滚动。

验收：覆盖零、一、二和额外命名窗口；时长相同但 ID 不同的窗口仍独立显示；刷新后同步调整尺寸且保留屏幕边缘；检查原生 fixture 截图并运行签名应用。账号访问、真实 Pro 和额外额度桶响应与 fixture 验证分别记录。Windows 仅更新版本信息。

[官方套餐文档](https://learn.chatgpt.com/docs/pricing)目前说明 Pro 无五小时限制；[app-server 文档](https://learn.chatgpt.com/docs/app-server#auth-endpoints)提供多额度桶。这些是按数据展示的依据，不能根据套餐名称擅自隐藏或创建窗口。
