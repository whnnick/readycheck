# 0.1.142：直接向内拖动

[English](PLAN.md) · [验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

问题：贴边后向屏幕中间拖动可能被悬停详情拦截，用户需要先上下拖动。

| 需求 | 成功标准 |
| --- | --- |
| 直接拖动 | 左右贴边竖条首次纯横向拖动就能回到自由圆球；展开表盘也能拖动。 |
| 指针捕获 | 鼠标按下即取消悬停计时，移动超过4点后拖动，指针离开窄竖条后仍持续接收移动。 |
| 点击与详情 | 不足4点仍视为点击；保留固定、收起、滚动和打开应用等详情控件。 |

范围：macOS圆球/贴边竖条窗口的鼠标处理及回归测试，本机更新到0.1.142。Windows只同步版本信息；本次不发布新的GitHub Release或改宣传视频。
