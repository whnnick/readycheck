# ReadyCheck 0.2.1：一个浮窗，交互更一致

[English](RELEASE_NOTES.md) · [功能检查](QA.zh-CN.md) · [计划](PLAN.zh-CN.md) · [版本索引](../../VERSIONS.md)

2026-10-17

- **圆球与竖条合并**：同一悬浮 Widget 靠左右边缘收成细竖条，向内拖动恢复圆球，共用详情、最近一小时消耗图和固定状态。旧贴边位置一次性迁移，原记录和之前的圆球位置保留。
- **信息卡片可自由移动**：拖动标题即可移动，按钮仍执行各自操作，重开继续记忆位置。
- **固定行为更一致**：点击预览内容、背景或空白区均可保持展开，包括展开过程中；取消固定后恢复预览，原有点击外部收起与 Esc 行为保留。
- **轮廓与动效修复**：贴边详情直接从细条展开，不再闪出圆圈；轮廓内描边避免被遮罩裁切，保留原生超采样遮罩。
- **更新介绍归入关于**：完整更新要点及说明链接集中保留在关于，连接设置不再重复展示。检查更新、配额窗口、账户权益、历史与凭据均保留。

“设置 → 显示”仅保留**悬浮气泡**和**信息卡片**两种选项，不新增自动弹窗。账号读取保持只读；ReadyCheck 不会自动停止／恢复 Codex 任务，也不会自动使用重置券。

## 下载与升级

- macOS：`ReadyCheck-0.2.1-macos.dmg`，Apple 芯片／macOS 14+。退出旧应用，替换应用程序内的 ReadyCheck 后重开。仍为自签名预览，**未经 Developer ID 签名或公证**。macOS 可能要求确认已有钥匙串访问，必要时在“设置 → 连接”重试读取；不因本次升级而要求重新 OAuth 登录。
- Windows：`ReadyCheck-0.2.1-windows-x64-portable.zip`，独立 x64 便携预览。本次仅同步版本元数据，沿用 Windows 原界面，Mac 原生 Widget 改动不适用于 Windows；自动打包检查不代替 Windows 实机验收。
