# 0.4.2 — 下一步交互更清楚

[English](PLAN.md) · [验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

发布范围：将总览下一步行的含糊箭头改为明确操作按钮。重置说明直接打开解释，其他操作保留原去向；静态信息不再暗示整行跳转。

使用节奏只显示一次结论，下方只保留一个展开入口。展开后直接说明当前原因、有效采样速度与适用限制，不重复标题／结论、不套卡片、不再嵌套折叠。暂停估算时显示“为什么暂不估算？”，有效估算显示“估算依据”；菜单栏及Widget点一次查看完整说明。

保留计算与资格规则、下一步排序、中英文信息、重置卡与提醒设置、账户权益、授权、历史及其他既有功能。用户现已授权打包推送0.4.2，正式交付检查在验收文档中跟踪。
