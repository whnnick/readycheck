| 范围 | 变化与证据 |
| --- | --- |
| 共享下一步 | 事件顺序和去向相同，总览改为静态信息加明确按钮；已实点重置说明与连接，卡片／规则／记录路由仍由NextEventsViewTests覆盖。此处有意调整点击方式，不移除去向。 |
| 使用节奏 | Core计算和阈值未改，单层说明替代嵌套视图，暂停态直接解释当前原因；真实总览及双语最小／波动状态渲染已验。 |

| H04 关于 | 保留入口／版号／完整说明，更新并渲染双语交互重点。 |
| D05／D09及I01 既有状态 | 开发安装后原授权文件和到期提醒尝试基线不变，开关保持开启；提醒／历史／自动用卡实现未改。 |
| 其他能力 | 无功能移除或偏好迁移，以既有准确路径证据和全量回归支撑保留行为，缺少硬件的范围继续标为未验。 |
