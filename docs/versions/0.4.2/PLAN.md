# 0.4.2 — clearer next-event interactions

[中文](PLAN.zh-CN.md) · [Checks](QA.md) · [Version index](../../VERSIONS.md)

Release scope: replace the ambiguous arrow in Overview’s next-event row with an explicit action button. Reset info opens its explanation; other actions retain their existing destinations. The row’s static information does not pretend to navigate.

Flatten quota-pace information to one visible conclusion and one disclosure. Opening it reveals the relevant reason, valid observation rate and limitations directly, without a repeated title, conclusion, nested card or second disclosure. Paused estimates say “Why no estimate?”; an estimate uses “How this is estimated”. Compact menu/Widget explanations open in one click.

Retain the calculation/eligibility rules, next-event ordering, bilingual content, reset-card and reminder settings, account benefits, authorization, history and all other existing functionality. The user has now authorized packaging and publication as 0.4.2; delivery checks are tracked in QA.
