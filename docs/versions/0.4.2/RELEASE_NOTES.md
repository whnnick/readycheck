# ReadyCheck 0.4.2 — clear actions, one layer of explanation

[中文](RELEASE_NOTES.zh-CN.md) · [Checks](QA.md) · [Feature retention](RELEASE_AUDIT.md)

- **Know what to click.** Up next replaces its ambiguous arrow with named Reset info, connection, rule and detail buttons. Reset info opens an explanation, not a quota reset.
- **Read once, expand once.** Quota pace shows one conclusion and one disclosure. Open it for the current reason and calculation limits, without another card or second disclosure.
- **Compact explanations open directly.** Menu and Widget open the full explanation with one click. Both quotas, the Widget last-hour chart and pinned behavior remain.

The calculation/eligibility rules, event order, quota data, account benefits, Token statistics, reminder controls, expiry deduplication, card-use authorization and history are retained. Real device checks covered Overview and Widget; bilingual minimum/unstable layouts use synthetic native rendering. No real reset card was consumed for acceptance.

New interactions are macOS-only. Windows retains its existing interface and synchronized version metadata. Mac remains an Apple-silicon self-signed preview, not Developer ID signed or notarized. Another live account, external displays, Windows hardware and real card redemption are not claimed as newly verified. See QA for the exact evidence.
