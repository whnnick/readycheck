# ReadyCheck 0.4.2 — 操作明确，说明一层看清

[English](RELEASE_NOTES.md) · [验收](QA.zh-CN.md) · [功能保留](RELEASE_AUDIT.zh-CN.md)

- **该点哪里，一眼看清。** “接下来”的含糊箭头改为重置说明、连接、规则和详情等文字按钮；重置说明只打开解释，不执行额度重置。
- **结论只显示一次，说明只展开一层。** 使用节奏点一次直接查看当前原因及计算限制，不再套卡片或出现第二个折叠入口。
- **紧凑入口直接看全。** 菜单栏及Widget一次点击打开完整说明，保留双额度、Widget最近一小时图及固定行为。

计算与资格规则、事件排序、额度数据、账户权益、Token统计、提醒开关、到期提醒去重、用卡授权和历史均保留。实机检查覆盖总览和Widget，双语最小窗口及波动状态使用原生合成渲染；验收未使用真实重置卡。

新交互仅针对macOS，Windows保留原界面并同步版号。Mac沿用Apple芯片自签名预览，非Developer ID签名、未公证。不宣称新增第二真实账号、外接屏、Windows硬件或真实用卡验收，具体证据见验收文档。
