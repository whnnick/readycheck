# ReadyCheck 0.5.0 — 提醒自己选，用卡有迹可查

[English](RELEASE_NOTES.md) · [黑盒验收](QA.zh-CN.md) · [65项功能保留](RELEASE_AUDIT.zh-CN.md)

- **自己选择何时收到到期提醒。** 在「设置 → 提醒」勾选72／48／24／12小时。原已处理节点、独立开关与账号授权保留；错过多个节点时合并提醒，不连续补发一串。
- **看清卡片发生了什么。** 总览与设置共用「用卡与检查记录」，可查看请求准备、已知服务端结果和独立的通知状态。卡片从可用列表消失时仍显示待确认，不直接写成已用成功。
- **保住已确认的成功回执。** 后续额度刷新失败不再丢失已确认的兑换结果。保持受保护账本打开、保存检查诊断，在不降低文件保护的前提下改善连续性；重复检查警告合并处理。
- **知道当前数据是否足够。** 数据状态与使用节奏直接解释连续观察时长、有效记录及中断原因；授权读取受限时显示待确认，不误显示关闭。

双额度、账户权益／重置次数、到期时间、Token统计、通知历史、Widget最近一小时图、固定／拖动、点击刘海和关于全部保留。新用户自动用卡仍需主动授权，已有授权原样保留；最早合格到期、指定卡片最后一小时检查、固定幂等重试和确认成功通知规则不变。

## 验证与边界

开发阶段全量398项Swift测试及最终定向／原生检查通过，真实读取、同包冷启动与实测锁屏／解锁已核验。公开源码、安装包与下载校验单独记录于[验收文档](QA.zh-CN.md)，不把开发通过等同于已经发布。

未为验收使用真实重置卡。历史夜间卡片结果仍未确认，新记录不能追溯证明当时由谁使用或是否过期。请求准备不等于网络请求已发出，系统接受通知不等于实际展示横幅。应用必须运行且账号与网络可用；睡眠、退出或访问受限仍可能导致无法及时用卡。

新增功能仅限Mac，Windows保留原界面。Apple芯片、macOS14+自签名预览，**未经Developer ID签名或公证**。新程序仍可能需要系统钥匙串确认，不承诺免确认升级。第二真实账号、外接显示器／Spaces、完整辅助功能与Windows实机的既有验收边界仍保留。
