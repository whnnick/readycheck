## 夜间事件——尚未查明

真实夜间记录显示，双额度在此前返回的重置时间之前同时恢复，随后一张卡不再出现在可用列表；本机执行账本无尝试记录，也无成功通知回执。这**不能确定**卡已使用、已过期或由哪个客户端发起。撤回此前“更可能过期”的解释。符合用卡条件的时段内确实观察到账本受保护读取失败，但这解释不了更早的双额度恢复。全量回归及后续真实读取通过，不能作为夜间兑换成功的证据。

开发期阻塞（dev.3已补齐诊断与可获取结果保留，历史追溯仍为明确边界）：持久化相关请求前失败诊断，并在有权威服务端结果时核对卡片状态；没有回执时，消失的卡必须保持未确认，不能补造成功执行或通知。事件发生于dev.3之前，当时仅保留本机尝试。dev.3已新增卡片观察与独立失败诊断；历史结果仍不能补造为确认成功。调查不得修改文件保护、原授权或消耗真实卡。
