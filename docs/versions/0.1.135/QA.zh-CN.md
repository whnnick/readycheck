# 0.1.135 黑盒验收

[English](QA.md) · [产品需求](PLAN.zh-CN.md) · [版本索引](../../VERSIONS.md)

状态：2026年10月11日在测试Mac完成实现与下列验收。发布包检查见下文，其他设备覆盖仍有限。

| 需求 | 结果与证据 |
| --- | --- |
| 全屏隐藏 | 本机贴边圆环、气泡和卡片通过。电脑工具操作Finder进入原生全屏，应用自身窗口遮挡日志均变为`visible=false`，退出后恢复`visible=true`；关闭开关后，贴边浮窗在全屏中保持可见。修正后的原生策略组合`canJoinAllApplications`与`fullScreenNone`，开启隐藏时不再使用`canJoinAllSpaces`。位置偏好、监控和提醒代码未改变。 |
| Token对比 | UTC边界、排除今天的两组完整7天、缺失/负值/重复/非法日期、上期为零和溢出均有确定性测试。已查看真实数据下的中英文安装版界面：今天缺失、最近一周不完整时显示未知合计、覆盖天数，不虚构变化。 |
| 悬停、移开与拖动 | 10月11日用户验收反馈“正常且顺畅”。自动测试覆盖短暂悬停、移开/重新进入、拖动、取消计时、点击固定、收起和桌面切换。 |
| 倒计时 | 既有测试覆盖缺失/过期/估算/模拟时间、分钟/天边界与到期等待刷新；真实安装版详情显示已验证的重置倒计时。本轮尚未观察真实重置到零的全过程。 |
| 账号与设置 | 使用既有“重试读取”恢复原OAuth登录，安装版显示当前真实额度；已恢复中文、右侧贴边样式及开启全屏隐藏。不迁移账号、身份或通知权限。 |
| 通知图标 | 10月10日用户确认Mac重启后C图标正常，见[0.1.133验收](../0.1.133/QA.zh-CN.md)。本版本不再清理通知缓存。 |
| 验证与安装包 | 通过：257项Swift测试、版本一致性、脚本语法、文档链接及本次范围敏感检查；Windows便携打包脚本的类型检查及smoke/UI检查。封装DMG内应用为0.1.135，沿用稳定身份且通过严格签名验证；Windows ZIP通过`unzip -t`，`dist`只保留当前两个平台安装包。 |

已完成：本轮范围内实现、自动检查与上述安装版验收。部分完成：Token悬停保留原图表覆盖层并增加变化文字，但电脑工具无法可靠持续停在柱形上，数值行为已测试。未完成：真实刘海屏/多显示器、其他桌面Space与台前调度组合验收，以及真实额度重置到零的观察；这些是后续环境检查，不标为通过。普通窗口最大化由原生窗口策略处理，不靠窗口大小推断。

发布阻塞项：本轮范围内测试与已观察界面无阻塞。预览版沿用稳定预览签名，Developer ID公证不属于本次发布。公开Release需要两个平台附件及公开同步敏感检查。

复现命令：`swift test --build-system native --scratch-path <临时目录>`、`scripts/check_release_consistency.sh`、`git diff --check`、`scripts/package_dmg.sh`、`scripts/package_windows_portable.sh`；对DMG挂载的应用执行`codesign --verify --deep --strict`，对便携ZIP执行`unzip -t`。全屏诊断可读取`com.readycheck.app`的`widget-spaces`调试日志，仅记录窗口可见状态及行为标志。
