# ReadyCheck 0.5.1 — 一眼更清楚，功能都保留

[English](RELEASE_NOTES.md) · [验收与边界](QA.zh-CN.md) · [65项保留审计](RELEASE_AUDIT.zh-CN.md)

- **总览先看重点。** 当前额度读取状态优先，近期趋势前置；套餐、订阅字段、Credits、每张卡的到期日和历史记录继续保留在完整账户权益中。
- **短暂失败少打扰。** 卡片明细短暂失败先静默重试，连续至少3次且持续2分钟才提示；凭据、账本和兑换结果不明仍立即处理。恢复后只撤回对应告警，历史不删除。
- **设置与实际状态一致。** 额度提醒、卡片到期提醒、自动用卡独立分组，控件靠右，显示当前账号开启／关闭／未知。完整规则一层查看，原授权、最后1小时用卡及成功通知不变。
- **统计周期不混淆。** Token账户汇总、固定周期比较与7／30／90天每日图分开；额度消耗仍为百分点，缺失Token日期不当成零。样式预览展示实际圆形↔贴边形态。
- **两种连接方式都在。** 本机Codex为主要入口，单独OAuth仍保留且不自动改来源。本机接口可能不提供订阅日期，即使额度、卡片正常；只允许匹配账号的登录资料补充日期，否则保留账单入口并说明来源限制，不编造有效期。
- **旧记录留在历史。** 仅来自旧提醒的缺失记录不再当作当前用卡异常，结果仍未确认。卡片只读详情保留事实／结果／通知／关闭，移除重复设置按钮。

双额度、主显示选择、恢复与低额度提醒、72／48／24／12小时节点、授权、成功通知、历史、Widget一小时图／拖动／固定、点击展开刘海、关于及全部原设置保留。未为验收花真实卡，也不宣称能自动停止／恢复Codex任务。

## 验证与分发

开发设计验收已通过410项Swift及最后11项定向检查；正式源码回归、包签名、远端与下载结果随完成写入QA。原生截图均为合成演示数据，真实原偏好、账号授权和请求账本已核对未变。旧硬件／换号／网络限制继续保留，不改写为已测。

Apple芯片、macOS14+自签名预览，**未经Developer ID签名或公证**；新包可能仍需macOS确认Keychain。Windows x64保留原界面，本轮原生设计更新仅适用于Mac。自动用卡仍需应用运行、账号访问和网络可用，休眠／退出／断网可能错过到期；不推断或补造历史用卡成功。
