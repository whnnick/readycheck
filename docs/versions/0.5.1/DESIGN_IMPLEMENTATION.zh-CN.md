# 0.5.1-dev.6 — 展示优化与功能保留

[English](DESIGN_IMPLEMENTATION.md) · [设计审查](DESIGN_REVIEW.zh-CN.md) · [计划](PLAN.zh-CN.md) · [黑盒检查](QA.zh-CN.md)

## 边界

设计约束要求原有能力完整保留。本次沿用原生 SwiftUI，只改展示；不新增依赖、偏好键、凭据迁移或存储结构，不改登录、额度计算、自动用卡和通知逻辑。下方开发证据为历史记录，正式发布验收另记QA。

视觉方向采用安静的明暗层次，优先组织监测信息。保留原生自适应底色、系统字体、额度语义色及系统蓝色控件；浮窗材质和系统导航继续作为原生设计的一部分。浏览器 CSS 检查器不能验收 SwiftUI，因此采用原生渲染、实点及下列检查。

## 改动

- 当前额度读取状态优先，最近成功时间作为历史信息；区分等待、刷新、凭据、读取失败、缓存、过期和已更新。原“接下来”模型继续单独说明卡片检查问题。
- 压缩双额度卡片，把重置卡数量、最近到期和趋势前置；套餐、有效期、Credits、全部重置卡日期和历史仍在图表下方直接展示，不增加折叠层级。
- 额度提醒、重置卡到期提醒和自动用卡分组，开关与阈值靠右对齐。自动用卡先显示当前账号开启／关闭／未知状态；完整规则一层展开，运行／休眠／断网限制仍直接可见，原启用确认不变。
- Token 时间选择移到每日图表旁，明确账户汇总覆盖已返回全部历史；保留固定比较周期、UTC 口径、精确提示及未知与零的区别。
- 样式预览展示圆形↔贴边竖条，替换代码符号。实际 Widget、刘海窗口与手势不改。检查记录跨日时同时显示起止日期。
- 静态面板减轻描边和阴影，浮窗材质保留。使用节奏说明改为有明确名称的一次点击浮层，完整内容保留。

## 功能保留对应

| 原能力 | 最终位置／保留机制 | 验证范围 |
| --- | --- | --- |
| 双额度、主显示、未知／缓存／过期 | 总览双卡、显示设置、当前状态、数据状态 | 展示状态回归；双语原生状态；选择和数据逻辑未改 |
| 套餐、有效期、Credits、卡数和全部到期日 | 图表下完整账户权益、图表前卡片摘要、原详情按钮 | 原生合成总览及真实读取／滚动检查 |
| 恢复提醒、低额度关闭／20／10／5 | 设置→提醒→额度提醒 | 原绑定与通知判定保留；回归 |
| 到期提醒开关和72／48／24／12小时节点 | 独立到期提醒组 | 原绑定、至少一项保护和去重保留；回归 |
| 按账号授权自动用卡、成功通知 | 独立自动用卡组、原确认框和历史 | 未改执行／授权／通知代码；集成回归；不花真实卡 |
| 用卡请求、旧未确认记录、检查与通知历史 | 原账号历史／详情及提醒“查看全部” | 历史、路由、恢复回归；不重写账本 |
| 数据状态、刷新、凭据重试、连接恢复 | 页首及原按状态恢复入口／连接设置 | 状态与连接竞态回归；原生流程 |
| 本机 Codex、单独 OAuth、重试／断开／回调 | 原连接主入口和其他方式 | 不自动迁移来源；双来源双语渲染及连接回归 |
| Token 汇总、比较、每日图／范围／提示 | 明确汇总与图表范围的 Token 页 | 聚合／比较未改；UTC／缺失日期回归 |
| Widget 一小时图、圆形↔贴边、卡片拖动／固定／位置／全屏 | 原 Widget 和显示控件 | 只改预览；共享界面及回归沿用原行为证据 |
| 物理刘海连接、点击展开、双额度、全屏 | 原刘海控制器和选择 | 未改刘海几何或事件，原证据保留范围 |
| 关于、更新要点、通用设置 | 原侧栏和通用／设置控件 | 原生分区与原导航保留 |

这是增量保留审计，不声称所有旧硬件／网络条件重新实测。真实换第二账号、外接屏、兑换卡和物理刘海几何不为展示调整而触发。旧审查中的刘海高度／连接页尾等可选后续建议仍待做，没有冒充实现或删除。
