## 验证记录

- 开发工作树及脱敏公开源码分别通过372项全量Swift测试。最后仅校正关于页中文措辞，两个源码树的双语关于页定向渲染通过。账本异常与六场景渲染检查也通过。
- 首轮受限环境失败来自NSScreen不可用和本机OAuth回环端口被拒；正常环境重跑通过，未削弱或跳过测试来制造通过。
- Windows使用Node24完成check／smoke／UI-smoke、ZIP完整性、ASAR版号及敏感文件扫描；Mac重构未移植到Windows。
- 最终Mac DMG只读挂载后，0.4.0版号、严格签名、包内隐私及两包目录不变量通过。正式安装的可执行文件与DMG内逐字节一致；用户确认钥匙串后，正式版真实读取、原授权及菜单操作通过。旧安装版完整备份可恢复，凭据、历史和偏好保留。
- 公开源码隐私、可见历史内部材料边界、版本一致性及299个本地Markdown链接通过；真实私有截图不作为发布素材。[原生总览](assets/release-overview-zh.png)、[Widget](assets/release-widget-zh.png)、[用卡结果](assets/release-card-result-zh.png)使用合成数据。
- 安装包为Apple芯片自签名预览（`ReadyCheck Preview Signing`），未经Developer ID签名或公证。既有Charts与构建工具警告不作为新失败。

产物摘要与远端交付状态见[发布证据](release-evidence.json)。用户已明确授权打包推送，未启用重复发布自动化。
