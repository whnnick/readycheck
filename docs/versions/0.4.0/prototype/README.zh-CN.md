# ReadyCheck 0.4.0-preview.1

[English](README.md) · [计划](../PLAN.zh-CN.md) · [验收](../QA.zh-CN.md) · [视觉检查](design-qa.zh-CN.md)

本地可点击设计原型，使用固定的2026年10月21日10:20北京时间合成数据。原生安装版仍为0.3.0，不访问凭据、官方读数、真实重置卡、系统通知或已有设置。

## 本地启动

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4333 --strictPort
```

打开Vite输出的本地地址，用外部场景选择器检查正常重置、自动用卡关闭、已授权等待、条件未确认、用卡成功但通知待重试五种状态。总览、菜单栏预览与Widget共享事件模型。卡片详情仅点击打开，Esc关闭。演示设置只保存在当前页面内存，刷新页面即重置。

## 验证

```sh
npm run test:scenarios
npm run test:sites
npm run build
```

构建包含模板自带的静态Worker，未部署。双语、窄窗口和视觉检查见版本验收与视觉检查文档。原型展示原有导航、权益和图表入口，不等于实现了65项原生能力，也不授权删除其中任何功能。原生持久化、迁移、真实用卡、通知投递及用户理解度验证均为后续独立工作。
