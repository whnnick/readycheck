## 五项视觉检查

- 字体：macOS/PingFang系统字体及等宽数字，保持参考层级；生成图字形不是可直接复用的字体文件。
- 布局：先双额度，后紧凑两条摘要、权益和完整消耗图；没有叠加大块“可用”或重复节奏卡。
- 颜色：深色中性面板、细分隔、蓝色操作、橙色条件提醒与绿色7天额度；CSS不冒充系统真实玻璃合成器。
- 素材：沿用产品图标、Phosphor图标及Recharts图表。
- 文案：保留双额度、次数和逐卡到期时间；区分Token与百分点、计时与实际恢复、尝试窗口与保证执行、用卡与通知结果，旧记录未记过程不虚构。
