# ReadyCheck 0.4.0——下一步，一眼清楚

[English](RELEASE_NOTES.md) · [验收](QA.zh-CN.md) · [功能保留审计](RELEASE_AUDIT.zh-CN.md)

## 更新重点

- **三处统一的下一步。** 总览、菜单栏与Widget展示同一个最相关的重置、条件用卡窗口或待处理事项；总览最多两条，避免再堆一个大状态卡。
- **用卡结果看得明白。** 从原有到期行或用卡记录点开详情，查看原到期时间、当前账号授权、已记录结果及对应成功通知。“用卡已成功、通知未送达”是等待通知投递，不是用卡失败。
- **数据新旧说清楚。** 保留卡片明细及其实际读取时间，过旧或不完整的读数不承诺尝试窗口。重置时间到了，也仍需新读数确认额度恢复。

## 原有功能保留

双额度与重置日期、套餐/订阅/Credits/重置次数及逐卡到期时间、低额/恢复/到期/自动使用独立控制、官方Token统计、本地消耗图与提示、Widget最近1小时/每柱5分钟图、主显示、自适应贴边、可移动卡片、仅点击展开刘海、固定/暂隐/可见性、连接诊断、更新、中英文菜单及关于均保留。[65项审计](RELEASE_AUDIT.zh-CN.md)记录对应证据及限制。

自动用卡继续需要原有按账号授权，本次新增的是只读解释，没有新增兑换或通用重试按钮。旧记录没有保存的执行过程明确标为未记录。额度节奏仍是有条件参考，不承诺准确工作时长，也不控制Codex任务。

## 发布范围

新增功能仅适用于macOS，Windows保留既有界面并同步版本元数据。Mac仍为Apple芯片自签名预览，未经Developer ID签名或公证。不能用合成测试推定真实兑换、另一个真实账号、外接显示器或Windows硬件已通过。

安装包验证、交付证据及覆盖边界见[验收文档](QA.zh-CN.md)。
