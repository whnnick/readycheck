# 0.1.136：连续外壳圆环气泡

[English](PLAN.md) · [黑盒验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

实现已选同心圆环设计，降低左侧详情与右侧表盘的割裂感。

| 需求 | 成功标准 |
| --- | --- |
| 连续外观 | 共用背景、轮廓和窗口遮罩；消除独立表盘外框、分离卡片、连接缺口及圆角外方形透明边。 |
| 真实双环 | 外环跟随主显示配额，内环展示下一项返回窗口；详情标签和百分比对应，额外窗口仍可滚动查看。未知/过期数据保留未知。 |
| 动效与位置 | 外壳、圆环和图标连续伸展；保留悬停半秒、点击固定、Esc/外部收起和拖动意图。自由气泡向空间较多的一侧展开，未受边界限制时保持表盘中心；贴边时向内展开。 |
| 最近一小时 | 从已有本地样本生成12个5分钟桶。明确返回的零与缺失不同；排除非法/未来值、缺失窗口边界、恢复、重置改变和超过10分钟的间隔。不增加轮询或换算Token。 |
| 兼容 | 保留C品牌、额度颜色、登录/通知身份、全屏设置、卡片/贴边/刘海入口和保存位置。Windows只同步版本号。 |

本次修改集中在已选圆形气泡方案，主窗口整理及其他视觉方向作为后续工作。本轮交付为本地预览安装和通过验证的本地提交。
