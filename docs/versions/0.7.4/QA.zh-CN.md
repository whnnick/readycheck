# ReadyCheck 0.7.4 验收

[English](QA.md) · [更新日志](../../../CHANGELOG.zh-CN.md)

## 0.7.4 正式版

- [发布范围](RELEASE_NOTES.zh-CN.md)包含 macOS 主窗口导航、键盘焦点和常驻聚合胶囊。公开源码共运行 561 项 Swift 用例，零失败，3 项需显式启用的用例跳过。14 项 Muse 读取测试通过。原生测试覆盖了回弹、快速反向切换、选中与焦点，以及聚合详情的悬停与固定。
- 挂载 DMG 后通过映像完整性、严格签名、版本、内置资源和私人路径检查。移走构建目录后安装版正常启动。实测设置菜单鼠标点选显示中性色玻璃底，方向键切换显示系统焦点环。
- 恢复钥匙串访问后，Codex 配额、Muse 周额度和 DeepSeek 余额均可见且各自手动刷新成功。聚合胶囊按原顺序显示和选中各项服务，可以重新打开主窗口。三服务恢复后，保存的胶囊帧与快捷展示勾选项和安装前完全一致。
- Windows 应用代码沿用 0.7.3。0.7.4 便携包通过 Node 24 服务、应用接线、界面冒烟、ZIP 完整性与内部 16 个应用源码文件比对。原报 OAuth 403 的 Windows 电脑暂无真实账户复测结果。

## 0.7.4-dev.3 鼠标选中与键盘焦点

- 左侧导航和顶部设置菜单的鼠标选中状态使用半透明玻璃底和细高光。键盘导航时在同一块胶囊上显示系统焦点色。
- 20 项 Swift 专项测试通过。安装版实测点选「通用」只显示玻璃底和细高光，按左方向键切到「显示」时出现蓝色焦点环，再点击「显示」时焦点环消失。
- 安装后 Muse 已恢复读数，Codex 和 DeepSeek 等待重新确认钥匙串访问。

## 0.7.4-dev.2 主窗口焦点

- 左侧导航和顶部设置菜单的焦点高光跟随同一块玻璃胶囊移动。键盘焦点单独移到未选中项时，用短线标记焦点。
- 18 项 Swift 专项测试通过，覆盖回弹和反向切换、聚合胶囊以及原生主窗口最低尺寸。已在 macOS 27.2.1 安装版实测主窗口的鼠标选择和方向键导航。
- 新版已读取 Muse，Codex 和 DeepSeek 等待重新确认钥匙串访问。

## 0.7.4-dev.1 玻璃选中动效

- 主窗口左侧导航、顶部设置菜单和常驻聚合胶囊共用带细高光的半透明选中底。切换时沿移动方向拉长并回弹，连续切换会接续当前速度。
- 侧边胶囊的外壳采用随系统明暗变化的磨砂材质。选中底跟随详情窗显示的服务，沿用原有额度圆环、固定状态、悬停延时、拖动把手和位置。系统减少动态效果时直接定位，降低透明度时显示实色。
- 35 项 Swift 专项测试全部通过，覆盖动效模型的拉伸、回弹和反向切换、聚合详情切换和位置、原生窗口渲染。用合成数据检查了胶囊的深浅两种外观。
- 移走构建目录后，在 macOS 27.2.1 打开签名安装版。实机核对了鼠标和方向键切换左侧导航及顶部设置菜单，胶囊边缘和垂直中心仍在原位置。Muse 恢复读数，胶囊可打开并固定其详情。
- 安装版三个真实服务之间的切换待 Codex、DeepSeek 完成钥匙串确认。合成数据的三服务悬停、固定及位置测试已通过。
