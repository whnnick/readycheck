# 0.1.99 计划：减少常驻额度浮层遮挡

[English](PLAN.md) | [验收](QA.zh-CN.md) | [版本索引](../../VERSIONS.md)

保留现有刘海状态条和桌面卡片。新增气泡作为桌面 widget 的默认形态，解决顶部控件有时被刘海状态条遮住的问题。同一时间只显示一种常驻浮层。运行时读取本机 Codex 或 ChatGPT 的应用图标，不随 ReadyCheck 分发复制的图标；应用身份仍为 ReadyCheck。

常驻气泡显示已验证的剩余额度，单击展开两个额度窗口，支持拖动。靠近屏幕左右边缘时收成窄标签；点击外部或按 Escape 收起。保存常驻位置，显示器变化后把浮层移回可用区域。隐藏后仍可从菜单栏找回。

验收条件：气泡／卡片选择在重启后保留；刘海继续可用；拖动和左右贴边都可操作；展开内容不出屏；过期或不可用数据不猜测百分比；未安装 Codex 与 ChatGPT 时图标安全降级。发布前须在实际运行的 macOS 应用中验收，并运行 Swift 测试。
