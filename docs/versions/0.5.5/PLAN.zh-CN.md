# 0.5.5 — 通知时间

[English](PLAN.md) · [验收](QA.zh-CN.md) · [版本](../../VERSIONS.md)

用户无法从 macOS 分组通知中看出何时发送。所有新通知在副标题显示“发送于”、完整本地化日期与本地时分。使用本次提交通知的实际时间，与正文中的卡片到期日、额度重置时间区分。覆盖七种通知，包括测试通知；保留原标题、正文、声音、标识、去重、权限检查和用卡授权。

现有通知记录页已有记录的尝试日期与时间，保留其时间及状态，不回写旧系统通知或历史记录。不新增兑换请求，不改变认证或持久化逻辑。macOS 展示修复，Windows 仅同步元数据。验收：双语内容测试、既有投递／重试／去重回归、通知中心实际测试通知。不使用真实卡验收。本轮为本地开发，未获新公开发布授权。
