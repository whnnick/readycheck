# 0.1.131 登录启动修复计划

## 问题与目标

运行中的预览副本丢失磁盘上的 Info.plist 后，macOS 无法构造登录项标识；界面只显示笼统错误。修复后必须区分安装不完整与系统注册失败，并让完整安装版可以正常开启和关闭登录启动。

## 范围

- 从磁盘检查应用标识、包类型和可执行文件，不依赖可能已缓存的 Bundle 元数据。不限制有效应用必须位于某个目录。
- 安装不完整时明确要求重新安装；系统错误时提供“打开登录项”，日志保留错误域和代码，描述标记为私有。
- 开发脚本通过现有打包流程启动 `.build/run` 中的完整签名应用，与会被清理的发布暂存目录分开。
- 日常使用安装至“应用程序”，保留旧版备份后替换本地安装，并验证 macOS 实际注册结果。
- 本版本只修复登录启动，不包含此前讨论的低额度提醒和暂时隐藏。Windows 仅同步版本号，不推送或发布。

## 成功标准

安装异常回归测试通过；完整测试、版本一致性和签名验证通过；真实界面可关闭、开启登录启动，重新打开后仍显示已启用。验收见 [QA](QA.zh-CN.md)。
