# 0.1.144：可靠的详情固定

[English](PLAN.md) · [验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

问题：圆球详情开启固定后，仍可能因点击外部或失去焦点而收起；详情减号与手动收起功能重复，使控制方式不够清楚。

| 需求 | 成功标准 |
| --- | --- |
| 固定保持展开 | 开启固定后，点击桌面、其他应用、ReadyCheck其他窗口或详情窗口失去焦点，圆球详情均保持展开。 |
| 恢复悬停预览 | 再次点击固定按钮后恢复悬停预览；移出圆球会收起预览，后续悬停仍按原有行为展开。 |
| 手动收起 | 详情获得焦点时，Esc仍可主动收起；移除详情减号按钮，以固定按钮控制持续展开。 |
| 清楚的提示 | 仅更新Bubble提示，说明当前固定或悬停预览状态；EdgeRail样式提示与交互语义保持不变。 |
| 范围 | 保持圆球/圆环几何、收起及展开尺寸、直接向内拖动和额度处理。Windows仅同步版本信息。 |

范围：macOS圆球详情的固定行为、控制按钮与Bubble专属提示。沿用现有测试及打包流程完成本地验证和安装。本地回归、打包和实际安装证据已记录于验收文档，尚未扩展的手工场景保留在待验收项中。公开[0.1.144 Release](https://github.com/whnnick/readycheck/releases/tag/v0.1.144)、latest状态、CI及回下载哈希验收均已完成，证据见验收文档。宣传素材是独立交付项。
