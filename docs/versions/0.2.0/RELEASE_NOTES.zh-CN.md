# ReadyCheck 0.2.0：额度一眼看清

[English](RELEASE_NOTES.md) · [验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

2026-10-16

- 更新 Windows 运行时至 Electron 43.5.0、打包工具至 20.3.0，并按新的 Node.js 22.12–24 要求检查环境；保留既有界面。
- 原生 Mac 应用重组为总览、Token 用量和设置，收紧菜单栏弹窗；侧栏和“更多”增加常驻“关于”入口，“关于”及产品说明突出本版更新。
- 保留 Widget 最近一小时消耗图、固定详情及细窄贴边竖条，显隐选择重启后仍保留；刘海与电脑刘海相连，只在点击时展开详情。
- Widget 与总览统一使用按账号隔离的本机额度下降记录，单位为百分点，讲清查看范围和每柱时长；总览支持悬停／点击查看柱子详情。官方每日 Token 数量单独展示，缺失时明确提示。
- 保留订阅有效期、Credits、主动重置次数及每次到期时间；指定额度缺失不乱切换，历史按账号隔离并保全旧备份，临时刷新失败不伪装为新鲜数据。
- 增加 5% 低额度提醒，补齐双语系统菜单及全屏快捷键。监控应用不自动停止或恢复 Codex 任务。
- macOS arm64 使用自签名预览签名，未经 Developer ID 签名或公证；Windows x64 便携预览沿用原界面，本次原生重构仅适用于 Mac。剩余设备／生命周期覆盖见版本验收文档。

本次升级 macOS 预览版；Windows 便携版沿用原界面。Mac DMG 适用于 Apple 芯片／macOS 14+，沿用自签名预览身份，未经 Developer ID 签名或公证。设备覆盖边界保留在验收文档中；合成截图只作展示，不作为真实账号证据。“关于”位于侧栏底部、菜单栏更多、应用菜单及设置 → 通用。Widget／总览展示本机额度消耗（百分点）；每日 Token 数量是独立的 UTC 官方统计，两者没有固定换算关系。
