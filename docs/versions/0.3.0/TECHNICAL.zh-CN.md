# 原生额度节奏契约

[English](TECHNICAL.md) · [计划](PLAN.zh-CN.md) · [检查](QA.zh-CN.md) · [功能保留](FEATURE_RETENTION.zh-CN.md)

2026-10-19，本地0.3.0-dev.1。总览、展开Widget及菜单栏共用纯函数`QuotaPace.evaluate`；不修改提醒、凭据、历史或其他应用的任务。

- 仅接受可用、非缓存的Codex app-server／OAuth读数，账号归属明确、明确允许普通使用、读数不超过120秒；未来时间、允许状态缺失及受限时不估算。
- 须有且只有一个已验证的300分钟百分比窗口，无受限代码，剩余比例有效，重置在未来5小时内。不用所选7天主额度替换5小时对象。
- 最多取最近1小时且不早于本周期起点；按提供方／账号过滤、排序，拒绝晚于当前读数的历史。从当前读数倒推连续后缀：相同窗口／重置（容差5秒）、比例有效、相邻间隔大于0且不超过10分钟、无额度回升。缺失／重复／异常／跨周期会断开连续性。
- 至少7个读数并覆盖30分钟；无下降显示空闲态。按实际间隔分别计算前后半段速度，较大值同时超过较小值3倍及每小时1个百分点时不估算。这些保守门槛是产品假设，不代表已测得预测精度。
- 用观测到的百分点下降／小时估算到目标线时间和重置时剩余；已经到线只陈述当前状态，不显示未来倒计时。显示时长按约5分钟取整。
- 保留关闭／5／10／20%选项。关闭时10%仅作明确标注的参考线，不开启通知；既有通知继续依据实际变化。紧凑入口展示条件性摘要，总览补充时段、速度、假设和可展开依据。

Widget最近1小时图继续对应用户原有主额度选择，标题写明额度窗口；新增摘要单独标记5h。展开尺寸为380×344点（增高40点），不以删除额度行、图表或按钮换取空间。信息卡片、刘海及手势语义保持原样。

最初开发阶段的发布阻塞（仅以下文发布范围决定明确取代的部分为准）：真实周期预测误差评估、实际睡眠／断网／账号／显示器覆盖及65项完整保留验收。合成原生渲染不代表真实预测精度。Windows只同步版本元数据，未实现其节奏界面。
