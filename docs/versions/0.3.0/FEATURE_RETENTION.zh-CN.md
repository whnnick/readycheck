## 旧版差异追溯

回查原生App直接本地化调用键：v0.1.145为291个，当前为300个；差集中16个旧键已按源码归类，不把字符串差异当作功能完成证明。动态标题、控制器及行为还需本表逐项检查。

1. 旧圆球／贴边独立设置和左右选择：此前用户已接受0.2.1统一悬浮Widget；保留两侧形态、直接拖回与位置记忆，不恢复重复样式选择器。
2. 旧收起／刘海打开入口文案：对应现有固定、Esc／外部收起及打开总览行为；该行为必须保留，不能只保留相似按钮文字。
3. 主显示缺失回退文案：0.2修复为指定窗口缺失显示未知，禁止悄悄切到另一个额度。
4. 数据过旧、显示设置、额度区和柱图标题：对应当前紧凑状态、显示分类、总览及统一图表口径；不是删除数据或设置。
5. 已由用户要求清理的Hook／全局notify实验不列为产品能力；不会借此恢复旧实验。

## 发布门槛与责任

开发方逐项填写实现位置、自动／黑盒结果、真实环境证据及迁移结果；受影响项不可用“源码还在”“原型有个同名入口”或总测试数代替验收。未实现、找不到入口、行为退化、数据丢失或待验项阻塞受影响版本发布。未修改路径可复用明确的既有证据并说明适用性。确需删改时，先给出该ID、旧／新行为、影响、替代方案及回滚办法，取得用户明确同意并记录证据，再更改决策。用户只需评审新增价值和明确提出的取舍，不承担发现漏项的责任。
