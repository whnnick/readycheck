# ReadyCheck 0.3.0

[English](RELEASE_NOTES.md) · [验收](QA.zh-CN.md) · [保留审计](RELEASE_AUDIT.zh-CN.md)

使用节奏参考、临期卡片控制和清晰的结果通知，同时保留已有额度、账户、Token及Widget功能。

## 0.3.0 更新重点

- **一眼看使用节奏：** 总览、菜单栏和Widget共享5小时额度的条件外推参考。需要足够的近期有效记录；工作强度变化可能带来较大误差，不代表准确可用时长。
- **临期卡片由你掌控：** 可按账号授权在最后1小时自动使用，优先最早到期的卡，默认关闭。服务端确认成功后发送专门通知，并记录投递结果。
- **提醒分别控制：** 到期提醒新增默认开启的独立开关，与恢复、低额度提醒及自动用卡分开控制。
- **保留常用信息：** 订阅有效期、Credits、重置次数/到期时间、官方Token图表和Widget最近1小时图均保留，主显示额度使用清晰文字标签。
- **连接恢复更稳妥：** 旧读取不会覆盖新连接，保留既有设置、凭据及账号历史。

## 开启自动用卡之前

默认关闭，须按账号明确授权；有效卡进入最后1小时后优先最早到期者，不依据剩余额度决定是否用卡。可重置窗口由服务端决定，使用不可撤销。须保持应用运行并允许系统通知；休眠、离线、认证失败或客户端不支持可能错过到期。未知结果只重试原卡和同一请求，确认成功则有独立通知与历史；升级保留已有授权选择。不购买Credits，验证未兑换真实卡。

## 平台与分发

Apple silicon、macOS14+，仍为自签名、未Developer ID签名或公证的预览分发。Windows x64保留既有界面，本次节奏/自动用卡特性仅适用于macOS。其他显示器/Spaces、网络和账号/设备条件保留文档中的验收限制。打包及远端交付状态见QA，准备本说明不等于已经发布。

设备验收限制：菜单栏实机、持续断网／恢复、真实换号及多显示器未完成。自动化功能覆盖不能替代这些实机结果；发布前已明确接受上述范围限制。
