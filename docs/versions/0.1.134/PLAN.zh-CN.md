# 0.1.134：重置倒计时与浮窗交互

[English](PLAN.md) · [黑盒验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

目标：让用户直接看懂距离配额重置还有多久，并统一气泡和贴边圆环的操作意图。

| 需求 | 实现范围 |
| --- | --- |
| 重置倒计时 | 气泡和贴边详情按每个窗口的官方 resetAt 显示天、小时、分钟，界面每30秒更新；悬停倒计时保留绝对重置时间提示。仅使用当前可用、已验证的 OAuth/app-server 数据。缺失、过期、估算数据显示重置时间未确认。到零显示等待刷新确认。 |
| 半秒悬停预览 | 气泡预览详情；最小贴边胶囊预览大胶囊圆环。短暂停留或拖动不展开，移开200毫秒后收起预览，重新移入取消收起。显式显示圆环仍先呈现大胶囊。 |
| 点击固定详情 | 点击气泡、预览详情或整个贴边胶囊，固定详情；移开不关闭。点击外部、收起按钮或详情获得键盘焦点后按Esc收起。主动收起后需移开再悬停，避免立即重新展开。 |
| 保留现有样式 | 圆形气泡仍可自由拖动，贴边圆环仍支持左右放置，卡片和刘海保留；气泡详情略增高，更多窗口可滚动。 |

不增加全屏隐藏、用量预测或新提供商；不新增网络轮询或模型请求。通知旧图标问题单独验收，用户10月10日确认重启Mac后已恢复，不自动发布。

验证覆盖时间边界、数据时效与来源、中英文文案、悬停取消、固定与移开、拖动和关闭计时；随后验收稳定签名的本机应用与真实配额。

技术参考：[Apple TimelineView](https://developer.apple.com/documentation/swiftui/timelineview)、[非激活面板](https://developer.apple.com/documentation/appkit/nswindow/stylemask-swift.struct/nonactivatingpanel)。
