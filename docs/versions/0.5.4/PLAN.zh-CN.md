# 0.5.4 — 重置卡详情收紧

[English](PLAN.md) · [验收](QA.zh-CN.md) · [版本索引](../../VERSIONS.md)

用户要求去掉底部多余分区，并明确授权验证后直接打包推送。移除最后一节分隔线，将固定高度由480点收紧至400点，保留540点宽度和原滚动区。卡片信息、结果、时间、请求明细、通知状态、关联通知弹窗、关闭／Esc全部保留；长内容可滚动。

不改凭据、账号归属、存储、提醒、用卡条件、授权、通知投递或接口。保留0.5.3独立通知页及导航／滚动修复和其他能力。macOS布局调整，Windows保留原界面。验证中英文原生短／长状态、关联通知、回归及最终签名安装；按既有流程完成公开源码复测、双包、敏感／历史检查、双语发布和实际下载摘要。沿用既有设备／真实用卡边界，不为测试消耗真实卡。
